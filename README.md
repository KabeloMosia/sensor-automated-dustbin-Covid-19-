# Sensor Automated Dustbin (Covid-19)

![Project Banner](https://via.placeholder.com/1000x300.png?text=Sensor+Automated+Dustbin)

## 📌 Overview
The **Sensor Automated Dustbin** is an innovative solution designed to reduce contact with waste bins, minimizing the spread of viruses like **COVID-19**. Using motion sensors, the dustbin automatically opens and closes its lid, promoting hygiene and convenience.

## 🚀 Features
- **Touchless Operation**: Uses sensors to detect motion and open the lid automatically.
- **Energy Efficient**: Designed to consume minimal power.
- **Compact & Durable**: Built with sustainable and long-lasting materials.
- **Smart Alert System**: (Optional) Can be enhanced to notify users when full.

## 🔧 Technologies Used
- **Arduino** for microcontroller operations
- **Ultrasonic Sensor** for motion detection
- **Servo Motor** for lid movement
- **Battery / Power Supply** for operation
- **C++ / Arduino IDE** for programming

## 🛠️ Setup & Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/KabeloMosia/sensor-automated-dustbin-Covid-19.git
   ```
2. Open the **Arduino IDE** and upload the code from `src/` to your **Arduino board**.
3. Connect the **Ultrasonic Sensor** and **Servo Motor** according to the circuit diagram.
4. Power up the system and test the touchless operation!

## 🎯 How It Works
1. The **ultrasonic sensor** detects a user’s hand when it comes near the dustbin.
2. The **servo motor** is triggered, opening the lid.
3. After a few seconds, the lid automatically closes.
4. The system resets, waiting for the next user.
